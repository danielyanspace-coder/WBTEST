# SELLIX

**AI-платформа аналитики и автоматизации для продавцов Wildberries.**
Весь бизнес на WB — в одном окне: аналитика, умные цены, автоответы на отзывы,
реклама, SEO и справочник с AI-чатом. Простой язык, без замудрённых слов.

> Стиль: **BENTO** — неоновый лайм (`#C7F503`) на почти чёрном фоне.

---

## 🚀 Запуск (локально)

```bash
cd sellix
cp .env.example .env      # заполните значения
npm install
npm run dev               # http://localhost:3000
```

## 🐳 Запуск на сервере (Docker)

```bash
cd sellix
cp .env.example .env      # заполните значения
docker compose up -d --build
```

Поднимет приложение (`:3000`) и PostgreSQL с pgvector (для AI/RAG).
