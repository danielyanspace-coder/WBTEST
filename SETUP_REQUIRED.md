# 📋 ЧТО НУЖНО ПРИСЛАТЬ, ЧТОБЫ ВСЁ ЗАРАБОТАЛО

Это единственный документ, который тебе нужен. Когда Claude развернёт проект на
сервере, он попросит у тебя значения из таблиц ниже. Пришли их — и продукт
заработает полностью.

> Большинство секретов можно сгенерировать прямо на сервере командой:
> `openssl rand -base64 32`
> Их не нужно «где-то брать» — просто создай случайные строки.

---

## 1. 🔴 ОБЯЗАТЕЛЬНО (без этого сайт не стартует)

| Переменная | Что это | Как получить |
|---|---|---|
| `NEXT_PUBLIC_APP_URL` | Адрес твоего сайта | Например `https://sellix.ru` (или IP сервера на старте) |
| `DATABASE_URL` | Строка подключения к базе | Если поднимаешь БД через наш `docker-compose`, оставь как есть. Для своей БД — дай строку вида `postgresql://user:pass@host:5432/sellix` |
| `AUTH_SECRET` | Секрет для входа/сессий | Сгенерируй: `openssl rand -base64 32` |
| `WB_KEY_ENCRYPTION_SECRET` | Ключ шифрования токенов WB продавцов | Сгенерируй: `openssl rand -base64 32` |
| `ADMIN_SECRET` | Пароль для загрузки справочника в ИИ | Сгенерируй: `openssl rand -base64 32` |

## 2. 🟡 ДЛЯ РАБОТЫ ИИ (чат по справочнику + автоответы на отзывы)

| Переменная | Что это | Как получить |
|---|---|---|
| `OPENAI_API_KEY` | Ключ OpenAI | На platform.openai.com → API keys → Create. Пополни баланс на $5–10 для старта |
| `OPENAI_CHAT_MODEL` | Модель для ответов | Необязательно. По умолчанию `gpt-4o-mini` (дёшево и хорошо) |
| `OPENAI_EMBED_MODEL` | Модель для поиска по справочнику | Необязательно. По умолчанию `text-embedding-3-small` |

> Без `OPENAI_API_KEY` сайт работает, но ИИ-чат и автоответы скажут «ИИ не подключён».

## 3. 🟢 ДЛЯ ПРИЁМА ОПЛАТЫ (подписки и реферальные)

| Переменная | Что это | Как получить |
|---|---|---|
| `YOOKASSA_SHOP_ID` | ID магазина ЮKassa | В личном кабинете ЮKassa после регистрации магазина |
| `YOOKASSA_SECRET_KEY` | Секретный ключ ЮKassa | Там же, раздел «Интеграция → Ключи API» |

> Без этих ключей биллинг работает в **тестовом режиме**: подписка включается сразу,
> без реальной оплаты (удобно проверить функционал). Как пришлёшь ключи —
> переключится на реальные платежи с автопродлением.

---

## 4. 🔑 Что вводит КАЖДЫЙ пользователь сам (тебе присылать не нужно)

**Токен Wildberries API** — каждый продавец вставляет свой токен прямо на сайте
(страница «Подключить WB»). Он создаётся в кабинете продавца WB:
**Настройки → Доступ к API → создать токен** (нужны категории: Контент, Цены,
Статистика, Аналитика, Отзывы, Продвижение). Мы храним его в зашифрованном виде.

---

## 5. ⚙️ Шаги после ввода данных (это сделает Claude на сервере)

1. Заполнить `.env` присланными значениями.
2. Запустить: `docker compose up -d --build`
3. Применить миграции БД: `docker compose exec web npm run db:migrate`
4. Загрузить справочник WB в ИИ (один раз, после ввода `OPENAI_API_KEY`):
   ```
   curl -X POST https://ТВОЙ_САЙТ/api/admin/ingest -H "x-admin-secret: ЗНАЧЕНИЕ_ADMIN_SECRET"
   ```
5. В кабинете ЮKassa указать адрес для уведомлений (вебхук):
   `https://ТВОЙ_САЙТ/api/billing/webhook` (только если подключаешь оплату).

После этого:
- регистрация/вход, пробный период 7 дней, подписки и рефералка (20%) — работают;
- продавец подключает свой WB-токен → подгружаются товары, заказы, остатки, отзывы;
- ИИ-чат отвечает по справочнику, автоответы на отзывы и умные цены — работают.

## 📨 Короткий чек-лист «что прислать»

```
NEXT_PUBLIC_APP_URL   = (адрес сайта)
AUTH_SECRET           = (openssl rand -base64 32)
WB_KEY_ENCRYPTION_SECRET = (openssl rand -base64 32)
ADMIN_SECRET          = (openssl rand -base64 32)
DATABASE_URL          = (оставить по умолчанию или своя БД)
OPENAI_API_KEY        = (ключ OpenAI)            ← для ИИ
YOOKASSA_SHOP_ID      = (если нужен приём оплаты)
YOOKASSA_SECRET_KEY   = (если нужен приём оплаты)
```

Полный список переменных с комментариями — в `sellix/.env.example`.
